# Task Planner

Приложение из двух страниц на данных [DummyJSON Todos](https://dummyjson.com/docs/todos) (254 задачи). Командная работа в паре через Git.

## Страницы

| Страница | Что делает | Ответственный |
| --- | --- | --- |
| `index.html` — Планировщик | Список задач, вкладки Все / Активные / Выполненные, поиск, прогресс-бар, отметка по клику | Участник A |
| `stats.html` — Статистика | Карточки-метрики, рейтинг топ-10 пользователей, задачи выбранного пользователя | Участник B |

Общее для обеих страниц: шапка с навигацией, загрузка данных, кнопка «🎲 Случайная задача».

## Структура

```
task-planner/
├── index.html        ← Планировщик (A)
├── stats.html        ← Статистика (B)
├── css/
│   ├── common.css    ← шапка, кнопки, модалка (вместе)
│   ├── planner.css   ← A
│   └── stats.css     ← B
└── js/
    ├── common.js     ← загрузка данных, случайная задача (вместе)
    ├── planner.js    ← A
    └── stats.js      ← B
```

## Запуск

Открыть папку в VS Code и запустить `index.html` через Live Server (расширение предложится автоматически).

## Правила работы

- A работает в ветке `feature-planner`, B — в `feature-stats`.
- Готовую часть вливаем через Pull Request. Напарник смотрит код и нажимает Merge.
- Файлы напарника не редактируем. `common.css` и `common.js` меняем только по договорённости.
- Коммиты маленькие и осмысленные: `Add tabs with counters`, а не `fix`.

## Технологии

HTML, CSS, JavaScript, [axios](https://axios-http.com/), [DummyJSON API](https://dummyjson.com/).
